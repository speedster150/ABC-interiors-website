# ABC Interiors Certification Project Package

This package is a starter implementation for the EPIXS Media certification assignment.

## Included
- index.html — responsive landing page
- styles.css — premium responsive styling
- script.js — popup + demo form behavior
- supabase.sql — required `leads` table schema

## Before production
1. Connect the enquiry form to a secure server/Edge Function that inserts into Supabase.
2. Connect the popup to the Mailchimp audience/signup mechanism.
3. Add real portfolio images and approved testimonials.
4. Deploy to Vercel.
5. Add Google Ads final URL + UTM parameters.
6. Build and activate the Mailchimp journey.
7. Perform the full test journey and capture screenshots.

The assignment requires live proof for each task, so do not claim a task as completed until it has been tested in the real account.
